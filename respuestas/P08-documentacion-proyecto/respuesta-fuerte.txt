# Banco de Prompts y Ejemplos 
  
> **Estado del repositorio:** Pendiente de confirmar (entorno sin archivos iniciales detectados en la inspección local). 
  
## 1. Descripción 
 Este banco de prompts está diseñado para ingenieros de prompts, desarrolladores de IA y equipos de producto que necesitan gestionar, probar y desplegar plantillas de prompts estandarizadas y reutilizables para modelos de lenguaje grande (LLMs). Permite mantener la trazabilidad, control de versiones y reproducibilidad de las interacciones con la IA. 
  
## 2. Estructura 
 Estructura de directorios propuesta/verificada: 
 . 
 ├── prompts/              # Almacén de plantillas de prompts (.yaml / .md) 
 ├── examples/             # Casos de uso de ejemplo con entradas y salidas 
 ├── tests/                # Pruebas automatizadas o scripts de validación 
 ├── scripts/              # Utilidades de ejecución y despliegue 
 └── README.md 

Convención de nombres: [dominio]_[accion]_[version].[ext] (Pendiente de confirmar según los archivos definitivos del repositorio). 

3. Requisitos 

Versiones: Python 3.10+ / Node.js 18+ (Pendiente de confirmar según manifiestos de dependencias). 

Dependencias: requirements.json / package.json (Pendiente de confirmar). 

Variables de entorno: 

OPENAI_API_KEY o clave del proveedor correspondiente (Opcional si se usan modelos locales, requerido para APIs comerciales). 

Servicios externos: APIs de proveedores de LLMs (Opcional/Dependiente del prompt). 

4. Ejecución 

Pasos estándar para la ejecución de los prompts: 

Clonar el repositorio y situarse en la rama de trabajo. 

Configurar el archivo .env con las variables de entorno necesarias (sin incluir valores reales). 

Ejecutar el script principal: 

python scripts/run_prompt.py --prompt prompts/ejemplo.yaml 

Ejemplo de entrada: 

{ 
   "input_text": "Resumir el siguiente artículo técnico..." 
 } 

Salida esperada: 

[Resumen generado estructurado en viñetas...]

Costes: El uso intensivo de las APIs asociadas conlleva costes económicos por token.
